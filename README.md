# 🅿️ Car Parking System (ລະບົບຈອດລົດ)

ໂປຣແກຣມລະບົບບໍລິຫານບ່ອນຈອດລົດແບບ Command-line ຂຽນດ້ວຍພາສາ **C**
รองรับการ Check-in / Check-out, ออกตั๋ว, บันทึกทะเบียนรถ, คำนวณค่าบริการ และชำระเงินผ่าน **LAO QR** (สกุลเงินกีบ / LAK)

---

## ✨ ຄຸນສົມບັດ (Features)

- **5 ຊ່ອງຈอด** — แสดงสถานะแบบ real-time (`Empty` / `Full` / `HOLD`)
- **ระบบ HOLD** — ล็อกช่องจอดชั่วคราวระหว่างทำรายการ กันการจองซ้อน
- **ออกตั๋วอัตโนมัติ** — สร้าง Ticket ID รูปแบบ `TK-<ช่อง>-<เลขสุ่ม>`
- **บันทึกทะเบียนรถ** — ทะเบียนลาว (เลข 4 หลัก) พร้อมตรวจสอบความถูกต้อง
- **Check-out ยืดหยุ่น** — ค้นหารถด้วย **Ticket ID หรือ ทะเบียนรถ** (เผื่อทำตั๋วหาย)
- **คิดค่าบริการอัตโนมัติ** — ค่าจอดพื้นฐาน + ค่าล่วงเวลาเมื่อออกหลัง 20:00 น.
- **ชำระเงิน 2 ช่องทาง** — เงินสด (พร้อมทอนเงิน) หรือสแกน **LAO QR** จริงแบบ ASCII
- **ป้องกัน input ผิดพลาด** — ตรวจสอบและวนถามใหม่เมื่อป้อนค่าไม่ถูกต้อง

---

## 💰 ໂຄງສ້າງຄ່າบริการ (Fee Structure)

| รายการ | ราคา |
|--------|------|
| ค่าจอดพื้นฐาน | **20,000 ກີບ** |
| ค่าล่วงเวลา (ออกหลัง 20:00 น.) | **+10,000 ກີບ / ຊົ່ວໂມງ** |

> ตัวอย่าง: ออกรถเวลา 22:30 น. → 20,000 + (3 ຊົ່ວໂມງ × 10,000) = **50,000 ກີບ**

## 🛠️ ຄວາມຕ້ອງການ (Requirements)

- **GCC compiler** (เช่น [MinGW-w64](https://www.mingw-w64.org/) หรือ MSYS2)
- Terminal ที่รองรับ **UTF-8** (สำหรับแสดงภาษาลาว และ QR Code)

---

## 🚀 ວິທີໃຊ້ງານ (How to Run)

### 1. Compile
```bash
gcc car_parking.c -o car_parking.exe
```

### 2. ตั้งค่า terminal ให้แสดงภาษาลาว/QR ได้ถูกต้อง (Windows)
```powershell
chcp 65001
```

### 3. รันโปรแกรม
```powershell
.\car_parking.exe
```

> 💡 **ขยายหน้าต่าง terminal ให้กว้างพอ** (อย่างน้อย 80 ตัวอักษร) ตอนแสดง QR Code เพื่อให้สแกนติด

---

## 📋 ເມນູຫຼັກ (Main Menu)

```
1. Check-in   — ນຳລົດເຂົ້າຈอด
2. Check-out  — ນຳລົດອອກ / ຊຳລະເງິນ
0. ອອກຈາກໂປຣເເກຣມ
```

**ຂັ້ນຕອນ Check-in:** เลือกช่อง (1-5) → ป้อนทะเบียน (4 หลัก) → ยืนยันออกตั๋ว
**ຂັ້ນຕอน Check-out:** ป้อน Ticket ID หรือ ทะเบียน → ดูใบเสร็จ → เลือกวิธีจ่าย (เงินสด / LAO QR)

## 🧩 ໂຄງສ້າງໂค้ด (Code Structure)

- `struct ParkingSlot` — เก็บข้อมูลแต่ละช่อง (สถานะ, Ticket ID, ทะเบียน, เวลาเข้า)
- `calculate_fee()` — คำนวณค่าบริการรวมค่าล่วงเวลา
- `display_qr_code()` — วาด LAO QR (EMVCo) แบบ ASCII ให้สแกนได้จริง
- `main()` — วนเมนูหลัก จัดการ Check-in / Check-out / ชำระเงิน
